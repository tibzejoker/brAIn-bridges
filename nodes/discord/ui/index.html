Step 1 · Create the application

Open the Developer Portal, click New Application, give it a name. Any name. You can change it later.

↗ Open Developer Portal

Step 2 · Bot tab — get the token + flip the intent

Once your application is open, click Bot in the left sidebar. You'll do two things here:

  1. Click Reset Token → confirm → Copy the long token shown. You'll paste it in Step 3.
    Discord shows the token once. If you miss it, just hit Reset Token again.
  2. Scroll down to Privileged Gateway Intents. Flip the Message Content Intent toggle on.
  3. Scroll all the way down → click the green Save Changes bar. Without saving, the bridge fails with "Used disallowed intents".

Step 4 · Invite the bot to a server (or DM it)

Waiting for the bot to connect — once it does, an invite link tailored to your bot appears here.

Open this link to add to a Discord server you administer. You'll pick which server in Discord's confirm screen.
