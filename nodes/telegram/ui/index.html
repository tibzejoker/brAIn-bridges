1 · Create a bot in Telegram

1

Open @BotFather in Telegram and start the chat.

↗ Open @BotFather (uses the official Telegram link)
2

Send this command to BotFather:

/newbot
3

BotFather asks for a display name (anything) and a username (must end with bot, e.g. my_brain_bot).

If your first username pick is taken, just try another one — BotFather tells you immediately.

4

BotFather replies with a token that looks like 123456789:ABCdefGhIJklmNoPQRstuvwxYZ-1234567. Copy it and paste below.

Treat it like a password — anyone with the token can act as your bot.

2 · Save the token

3 · Start talking to your bot

5

https://t.me/<your_bot_username> ↗ open
